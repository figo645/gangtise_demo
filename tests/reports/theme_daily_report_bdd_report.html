接口与日期说明

早报使用 type=[morning]，午间报使用 type=[noon]，晚报使用 type=[night]。当前 API 契约不包含 startDate/endDate，因此若服务端只返回最新一份主题日报，无法通过此接口强制读取历史 9 月 17 日版本；需要上游返回 reportDate/date 或提供历史查询参数后才能严格验收。
