SECTION 01

产品概述

洞见智研是面向投资者与研究型大V的多租户投研平台。当前交付以真实市场数据、租户知识、复盘生产与 Hermes 研究问答为主线，并由独立 Admin 管理功能开关、模型、数据治理和审计。

基本信息
项目内容
产品名称洞见智研金融科技 · 投研数据平台
当前版本v1.4
文档日期2026-08-13
产品定位以租户隔离的市场数据、知识资产和证据链为基础，支持投资者跟踪、大V研究生产与平台治理
技术栈Flask · Python · PostgreSQL / pgvector · HTML5 · CSS3 · JavaScript · ECharts
核心价值主张
① 研究辅助优先
面向投资者提供行情、自选股、复盘阅读、知识和消息；面向大V补充复盘生产、知识录入与粉丝经营；所有研究输出坚持“结论可追溯、数据来源可说明、不构成投资建议”。
② 主题一致性与咨询风体验
产品默认采用白底咨询风，并保留深色模式与主题色切换。首页、H5、PRD、admin 共享同一套主题配置，保证文档与产品状态同步。
③ 多租户、权限与能力开关
普通用户、大V与 Admin 使用独立权限边界。H5 和工作台按所属租户读取内容；Admin 才可配置功能开关、Hermes 访问范围、互动权限和登录策略。会员、社区和机构 API 尚未作为已交付功能。
④ 模型按功能精细路由
所有大模型应用统一纳入平台配置，但不再要求全站共用一个模型。Admin 已支持按功能独立选择模型，优先满足 Hermes、复盘、知识加工、评论标注等不同链路的稳定性与成本控制。

Production → Staging 全量同步以 Production 快照重建 Staging 临时库，校验通过后切换。用于刷新测试基线；原 Staging 会被替换，旧 Staging 保留回滚备份。
取消或失败最终数据库切换前可取消；失败时清理临时数据库与导出文件。已完成的增量包不会自动回退；全量切换完成后通过目标环境的回滚备份执行恢复。
默认决策：日常发布选择“Staging 验证 + Production 增量”；不要因为 Staging 测试通过就默认用全量数据库覆盖 Production。只有确认两端业务数据可被完整替换时，才选择 Staging → Production 全量同步。
