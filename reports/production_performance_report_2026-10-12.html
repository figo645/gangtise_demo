关键发现

高 1. 生产环境配置标识不正确

/api/runtime-environment 返回：

{"is_production":false,"label":"本地开发","target":"local"}

这可能影响日志级别、功能开关、第三方回调、错误展示、数据保护和发布流程。

高 2. 首页资源体积过大

首页 HTML 原始约 5.48MB，启用 gzip 后仍约 1.20MB。代码中首页内嵌了较大的站点配置和长页面内容，可能造成移动端首屏慢、渲染耗时和并发带宽压力。

中 3. 首页响应时间波动

浏览器导航约 1.73s，而命令行单次采样为 7.41s，后续低频采样达到约 9–11s。需结合服务端日志、Gunicorn worker、数据库慢查询和上游依赖进一步定位。

整改建议

  1. 立即修正生产环境变量、运行标识和回调配置，并增加启动时环境校验。
  2. 拆分首页内嵌 SITE_CONFIG 与非首屏内容，采用接口加载、懒加载和分页；静态 CSS/JS 独立缓存。
  3. 检查 Gunicorn worker 数、超时、数据库连接池、模板渲染耗时及慢查询。
  4. 补充只读压测账号和固定测试数据，在业务低峰进行 10/25/50 并发阶梯测试，记录成功率、P50/P95/P99、吞吐量和错误类型。
  5. 为首页和核心 API 建立持续监控：首字节时间、完整响应时间、响应体大小、5xx、超时和数据库耗时。

测试边界

  • 测试仅覆盖公网可达性、页面导航和公开/鉴权 GET 接口。
  • 命令行网络访问需要额外网络权限；浏览器直接打开 API 路径受客户端安全策略限制。
  • 未提供测试账号，故未执行登录态业务链路。
  • 为保护生产系统，未执行破坏性操作、写操作或持续高并发压测。
