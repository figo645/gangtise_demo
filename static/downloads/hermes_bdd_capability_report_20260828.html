结论

BDD 场景

1

今日个股咨询分析

PASS
Given
用户输入“对今天中国银行的股票做下个股分析，看看今天整体情况怎么样”。
When
LLM 路由为 stock_today_observation；服务端确认中国银行为 601988.SH。
Then
只调用一次 gangtise.stock_today_observation，其 SSE 参数为 mode=deep_research；返回行情、逻辑、要闻、风险并直接展示。
2

今日大盘综合分析

PASS
Given
用户输入“分析下今天大盘的整体走势，上证和深证指数表现如何”。
When
LLM 路由为 market_today_observation，目标类型为 index。
Then
只调用一次 gangtise.market_today_observation，使用 deep_research，直接展示指数表现、板块资金与情绪展望。
3

个股结构化深化研究

PASS
Given
用户输入“对中国银行做一下深入研究”。
When
LLM 路由为 stock_one_pager，并确认仅一只股票。
Then
只调用一次 gangtise.stock_one_pager，直出最近一期报告；明确其为非当日研究，空返回严格报错而不降级生成。
4

多股票精炼看点

PASS
Given
用户输入“中国银行、建设银行、招商银行，帮我简单介绍分析下”。
When
LLM 路由为 stock_highlights，确认三只证券。
Then
只调用一次 gangtise.stock_highlights，逐只展示上游看点；不调用本地 LLM，不声称完整观察报告或组合结论。
5

多自选股详细综合分析

PASS
Given
用户输入“中国银行、建设银行、招商银行，做详细的综合分析”。
When
LLM 路由为 multi_watchlist_analysis，服务端要求至少两只已确认证券。
Then
只调用一次 gangtise.multi_watchlist_analysis，使用 deep_research，直接展示个股要点和组合综合结论。
6

多轮闲聊与投资教育

PASS
Given
用户输入“我该怎么选股呢？”。
When
LLM 路由为 small_talk，工具列表为空。
Then
不调用 Gangtise 或本地行情工具；配置的大模型完成自然语言回答，并保留会话上下文供下一轮使用。
